
# The-Tector: Fake News

##  To Run:
    1. get the trained_dataset.pkl from the gdrive provided below.
    2. put it in 'fakeh_news/app/src/files/trained_dataset.pkl'
   
    3. cd fakeh_news
    4. ngrok http 8000
    5.  uvicorn app.main:app --reload
